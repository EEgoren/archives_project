# Коллекция веб-архивов

Этот репозиторий содержит коллекцию веб-архивов разных тематических сайтов, созданную с использованием инструментов **wpull**, **metawarc** и **ArchiveReady**, а также подробную документацию по структуре каждого архива, его качеству и особенностям веб-архитектуры.
Коллекция отражает разные типы веб-проектов - от визуальных справочников до минималистичных статических сайтов, образовательных ресурсов и интернет-арта.

---

## Краткое описание коллекции

В коллекцию входят следующие сайты:

1. **AirportCod.es** - визуальный справочник IATA-кодов аэропортов.
2. **MarkdownGuide.org** - авторитетный ресурс по синтаксису Markdown.
3. **Solar Low-Tech Magazine** - автономный сайт, посвящённый низкотехнологичным решениям, по словам разработчиков работает от энергии солнца.
4. **100r.co** - проект о минимализме, путешествиях и низкотехнологичном программировании.
5. **Cat-Bounce Message** - отдельная арт-страница из проекта Cat-Bounce.

Эти сайты были отобраны как примеры *разных типов интернет-культуры* - образовательной, художественной, технологической и документирующей.

Каждый сайт архивировался полностью: HTML, изображения, JSON, JavaScript, CSS, PDF и другие форматы, являющиеся частью их структуры.

---

## Метод и технологии

Работа над коллекцией включала три ключевых инструмента:

### 1. **wpull**

Использовался для создания WARC-архивов с рекурсивной загрузкой, CDX-индексами и базами данных (`*.db`).

### 2. **metawarc**

Этот инструмент применялся для:

* анализа MIME-типов;
* извлечения метаданных (`*.jsonl`);
* создания индексной базы (`metawarc.db`);
* статистики по расширениям.

Он позволил составить полноценный профиль каждого архива.

### 3. **ArchiveReady (методология CLEAR)**

Сервис оценивал архивируемость сайтов по параметрам:

* **Cohesion** (внутренняя связанность)
* **Accessibility** (доступность)
* **Metadata** (корректность HTTP-заголовков)
* **Standards Compliance** (соответствие веб-стандартам)

Результаты дают понимание того, насколько легко сайт может быть сохранён в долгосрочной перспективе.

# Структура репозитория

Для каждого сайта выделена отдельная папка:

Каждая папка содержит:

* **README.md** — подробный отчёт по `wpull`, `ArchiveReady` и `metawarc`
* ***_meta.jsonl** — метаданные WARC-файла
* **metawarc.db** — индексная база
* **WARC-файл** или ссылка на него
* скриншоты:

  * ReplayWeb.page
  * ArchiveReady summary

# Итог

Коллекция объединяет сайты, различающиеся по тематике, структуре и визуальной насыщенности, что позволяет:

* исследовать разные стратегии веб-архитектуры;
* сравнивать типы контента и веб-практик;
* анализировать архивируемость проектов;
* учиться правильным методам сбора, анализа и документирования веб-архивов.

Методика, использованная в проекте, обеспечивает **полную воспроизводимость**, **долговременную сохранность** и **исследовательскую пригодность** собранных материалов.
